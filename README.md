# Texture Packer Fast
Free texture packer creates sprite sheets for you game or site. Rotation, trimming, multipacking, various export formats (json, xml, css, pixi.js, godot, phaser, cocos2d). Zip support. Split sheet tool. 9 slice tool.

Бесплатный текстурный пакер создает спрайт-листы(атласы) для вашей игры или сайта. Поворот, обрезка, мультипакетирование, различные форматы экспорта (json, xml, css, pixi.js, godot, phaser, cocos2d). Поддержка ZIP. Инструмент для разделения атласов. Инструмент для создания 9 slice разметки.

Test Platform: Windows 11 (Stable operation is also possible on later versions.)
